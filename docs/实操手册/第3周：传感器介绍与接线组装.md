<img src="../images/week_3/3-1.png" width="450" />

飞控引脚颜色与功能速查

为了方便快速识别，行业内通常用不同颜色的线缆来区分信号类型。下表整理了常见引脚颜色对应的功能，接线时可以对照确认：

|线缆颜色|引脚名称|信号类型|主要作用|常见连接设备|
|---|---|---|---|---|
|红色|5V / 12V / VBAT|电源输入/输出|给外部设备提供工作电压|GPS、接收机、图传、传感器|
|黑色|GND|电源地|电源负极、信号参考地|所有外设必须连接|
|黄色|RX|UART接收|接收外部设备发送的数据|GPS、遥控器、数传、图传|
|绿色|TX|UART发送|向外部设备发送数据|GPS、遥控器、数传、图传|
|蓝色|SDA|I2C数据|I2C总线数据传输|罗盘、传感器|
|绿色|SCL|I2C时钟|I2C通信时钟同步|罗盘、传感器|
|白色|PWM / 信号线|控制信号|输出控制脉冲|电机、电调、舵机|
|紫色|LED / IO信号|控制信号|外部LED控制|状态灯|
|棕色|Beeper|控制信号|蜂鸣器控制|蜂鸣器报警|

## 2.7 传感器接线

### (1) 接线基本原则

在动手之前，先牢记以下接线原则。核心思想可以概括为：动力线路保证"安全供电"，信号线路保证"稳定通信"，敏感设备保证"远离干扰"，线束设计保证"可靠维护"。

对于搭载RTK、激光雷达和机载计算机的行业无人机，合理的接线布局直接决定系统可靠性和飞行稳定性。

|要点|要求|目的|
|---|---|---|
|接口对应|严格按照飞控接口定义连接，不可随意插接|防止设备损坏|
|电源匹配|确认电压、电流范围，禁止高压供电|保护电子设备|
|正负极正确|红线接正极（+），黑/棕线接负极（GND）|防止烧毁设备|
|信号方向正确|TX接RX，RX接TX，信号线接对应接口|保证通信正常|
|线序确认|插接前检查针脚定义和颜色|避免反接|
|固定可靠|接头插紧，线路绑扎固定|防止飞行震动导致断线|

# **总结**

本次课程详细介绍了无人机传感器的接口定义和完整的接线组装流程。从飞控接口识别到最终的桨叶电池安装，每一个步骤都需要严格按照规范操作。

## 1.要点回顾

整个组装过程可以概括为以下几个关键环节：

|步骤|核心内容|关键检查点|
|---|---|---|
|接口识别|了解飞控各接口定义和线序|UART2为Debug口不可用，SPI0不建议使用|
|光流安装|MTF\-02P粘贴到底板凹槽|测距探头朝前，光流镜头朝后|
