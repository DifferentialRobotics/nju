# 实践二：飞行日志分析

## 2\.1 图表共同功能

Flight Review生成的飞行图表具备许多共同功能，帮助用户更直观地理解飞行数据：

- **图表背景颜色**：用于指示记录期间的飞行模式，不同颜色代表不同的飞行模式（如手动、定点、任务等）

- **飞行模式标识**：图表主体的背景颜色表示当前飞行模式，可以直观看到不同阶段的飞行状态

- **VTOL飞行模式**：对于垂直起降飞行器，还会在图表底部以背景颜色显示VTOL模式，蓝色代表多旋翼模式，黄色代表固定翼模式，红色代表过渡阶段

在图表上可以用鼠标框选某个时间段进行放大查看，也可以将鼠标悬停在曲线上查看具体数值。通过对比不同颜色的背景区域，可以分析不同飞行模式下的无人机表现。

## 2.2 PID性能跟踪分析

根据飞行模式的不同，飞行器控制器可能会尝试跟踪位置、速度、高度或速率设定值。具体跟踪的设定值取决于当前飞行模式，例如在自稳模式下没有速度设定值，而在定点模式下会跟踪位置设定值。

在Flight Review的PID性能跟踪图表中：

- **绿色线条**：表示设定值（期望值），即控制器想要达到的目标值

- **红色线条**：表示估计值（实际值），即传感器测量到的实际飞行状态

理想情况下，估计值（红色线条）应与设定值（绿色线条）紧密匹配。如果两者不匹配，在大多数情况下，需要调整该控制器的PID增益。查看日志有助于评估调参效果，判断PID参数是否合适。

<div style="background-color: #f1f1d1ff; border-left: 5px solid #b9b625ff; padding: 10px 15px; margin: 15px 0; border-radius: 3px;">
<strong>​​​💡 条参依据<br>
通过对比设定值和实际值的曲线，可以直观地判断控制性能。如果实际值总是滞后于设定值，说明P增益过小或系统响应过慢；如果实际值出现明显超调和振荡，说明P增益过大或D增益不足。

</strong>
</div>

<div style="background-color: #f1f1d1ff; border-left: 7px solid #b9b625ff; padding: 10px 15px; margin: 15px 0; border-radius: 3px;">

## 2\.3 振动性能分析

振动是多旋翼飞行器最常见的问题之一。高振动水平可能导致：1)飞行效率降低，飞行时间缩短；2)电机温度升高；3)材料磨损加剧；4)飞行器难以精确调校，导致飞行性能下降；5)传感器故障。因此，关注振动水平并在必要时改进设置非常重要。

### \(1\) FFT频率分析

FFT（快速傅里叶变换）是基于执行器控制信号（速率控制器的PID输出），展示了横滚、俯仰和偏航轴的频率图。它有助于识别频率峰值，并配置软件滤波器。

理想情况下，在最低端（约20Hz以下）应只有一个单一峰值，其余部分应较低且平稳。如果在较高频率出现明显峰值，说明存在机械振动问题，需要检查电机、桨叶和机架结构。

<div style="background-color: #f1f1d1ff; border-left: 7px solid #b9b625ff; padding: 10px 15px; margin: 15px 0; border-radius: 3px;">
<strong>​​​💡 振动的危害：<br>
高振动不仅会影响飞行稳定性和控制精度，还可能导致IMU传感器数据失真，进而影响姿态估计和导航精度。严重的振动甚至可能导致结构疲劳和零部件损坏。因此，在PID调参之前，必须先确保机械振动处于可接受的水平。

</strong>
</div>

### \(2\) 原始加速度分析

原始加速度图表展示了x、y和z轴的原始加速度计测量值。理想情况下，每条线都应较细，且能清晰显示飞行器的加速度变化。

一般经验法则是：如果在悬停或缓慢飞行时，z轴图表与x/y轴图表相交，则说明振动水平过高。正常情况下，z轴加速度应在1g（重力加速度）附近波动，而x/y轴加速度应在0附近波动。如果x/y轴的波动幅度接近或超过z轴的波动幅度，说明存在较大的横向振动。

<div style="background-color: #f1f1d1ff; border-left: 7px solid #b9b625ff; padding: 10px 15px; margin: 15px 0; border-radius: 3px;">
<strong>​​​💡 判断标准：<br>
良好的振动水平下，原始加速度曲线应该是三条清晰、细窄的曲线，z轴在约9.8m/s²附近，x/y轴在0附近。如果曲线变得很粗、噪声很大，或者x/y轴的波动幅度明显增大，说明振动问题需要解决。

</strong>
</div>

### \(3\) 加速度功率谱密度

加速度功率谱密度是一个二维频率图，展示了原始加速度计数据随时间的频率响应（显示x、y和z轴的总和）。区域颜色越黄，表明该时刻和频率的频率响应越高。

理想情况下，只有几Hz以下的最低部分为黄色，其余部分大多为绿色或蓝色。如果在较高频率区域出现大面积黄色，说明存在明显的高频振动，需要排查机械振动来源。

<div style="background-color: #f1f1d1ff; border-left: 7px solid #b9b625ff; padding: 10px 15px; margin: 15px 0; border-radius: 3px;">
<strong>​​​💡 排查方向：<br>
如果检测到异常频率成分，需要重点检查：1)飞控安装是否牢固，是否有减震措施；2)电机固定是否松动，电机轴承是否磨损；3)桨叶是否平衡，是否有损伤；4)机架结构是否存在共振。通过紧固和调整可以有效降低振动干扰。

</strong>
</div>

## 2\.4 制动器输出分析

"执行器输出"图表显示发送到各个执行器（电机/舵机）的信号。通常，该信号范围在配置的PWM最小值和最大值之间。

如果一个或多个信号长时间处于最大值，意味着控制器进入饱和状态。这不一定是问题，例如在全速飞行时，这是预期情况。但如果在正常任务飞行中出现这种情况，则表明飞行器可能超重，无法提供足够的推力，或者PID参数设置不当导致输出过大。

<div style="background-color: #f1f1d1ff; border-left: 7px solid #b9b625ff; padding: 10px 15px; margin: 15px 0; border-radius: 3px;">
<strong>​​​💡 饱和状态判断：<br>
正常悬停时，各电机输出应在中等水平（约50%-70%），且各电机输出相对均衡。如果某个电机长期满负荷输出，说明动力分配不均或飞行器重心偏移。如果所有电机都接近满负荷，说明推重比不足，需要减轻重量或更换更大推力的动力系统。

</strong>
</div>

# 实践三：PID调参

## 3\.1 开启High rate高速率日志

在进行PID调参之前，首先需要开启High rate（高速率）日志功能。开启后，飞控会以控制环原生高频频率记录姿态控制相关数据。

PID属于毫秒级快速闭环控制，普通低速日志的采样率不足，无法用于分析振荡、响应滞后、超调等控制问题。只有高速率日志才能完整捕捉控制环的动态响应过程，为PID参数调校提供准确的数据依据。

<div style="background-color: #f1f1d1ff; border-left: 7px solid #b9b625ff; padding: 10px 15px; margin: 15px 0; border-radius: 3px;">
<strong>​​​💡 开启方法：<br>
在QGC地面站的参数设置中，找到SDLOG\_PROFILE参数，勾选"High rate"选项，或者设置相关的日志速率参数。开启后重新飞行，记录的日志将包含高频姿态控制数据。

</strong>
</div>

<div style="background-color: #f1f1d1ff; border-left: 7px solid #b9b625ff; padding: 10px 15px; margin: 15px 0; border-radius: 3px;">
<strong>​​​💡 注意事项：<br>
高速率日志会产生更大的数据量，占用更多的SD卡存储空间。建议在调参完成后关闭高速率日志，恢复正常日志记录模式，以节省存储空间。

</strong>
</div>

## 3\.2 Cutoff滤波器参数概念

### \(1\) 总体概念

滤波器截止频率（Cutoff）是PID调参中的关键参数。总体原则是：cutoff低，噪声小但是延迟大；cutoff高，延迟小但是噪声大。需要在噪声抑制和控制延迟之间找到平衡点。

### \(2\) IMU\_GYRO\_CUTOFF参数

IMU\_GYRO\_CUTOFF影响主陀螺仪送往控制器的角速度，是二阶Butterworth低通滤波器的截止频率。在PX4当前控制链中，gyro数据先经过notch（陷波滤波器），再经过IMU\_GYRO\_CUTOFF，得到供P/I项使用的角速度；然后对角速度求导，再经过IMU\_DGYRO\_CUTOFF，得到D项使用的角加速度。

<div style="background-color: #f1f1d1ff; border-left: 7px solid #b9b625ff; padding: 10px 15px; margin: 15px 0; border-radius: 3px;">
<strong>​​​💡 滤波器作用：<br>
低通滤波器允许低频信号通过，同时衰减高频信号。陀螺仪数据中包含有用的姿态变化信息（低频）和机械振动噪声（高频）。截止频率决定了哪些频率的信号能够通过，哪些被滤除。

</strong>
</div>

## 3\.4 分析系统振动性能

在进行PID调参之前，首先需要确保系统的振动性能处于良好状态。振动过大会严重影响PID控制效果，导致参数难以调校。

1. 录制Position（定点悬停）模式飞行日志

2. 利用飞行日志中的Actuator FFT参数，检查无人机振动情况

3. 正常情况下，频谱应主要表现为直流分量，不应存在明显的其他频率峰值

若检测到除直流分量外的异常频率成分，则需要进一步排查机械振动来源，重点检查飞控安装、电机固定、桨叶平衡以及机架结构是否存在松动或异常，并通过紧固和调整降低振动干扰，确保飞控系统稳定运行。

<strong>​​​💡 振动排查步骤：<br>
1)检查飞控是否使用减震垫安装，安装是否牢固；2)检查电机螺丝是否紧固，电机轴承是否有异响；3)检查桨叶是否有损伤，是否做过动平衡；4)检查机架螺丝是否全部紧固，是否存在结构共振。逐一排查并解决问题后，重新录制日志验证振动水平。

## 3\.6 手动模式PID调校过程

手动模式PID调校是提升无人机控制性能的关键步骤。调校过程需要循序渐进，逐步调整各参数，观察飞行响应的变化。

### \(1\) 调校顺序与原则

首先迭代调整横滚（Roll）和俯仰（Pitch）的P、D增益，再调整I增益。初始阶段，横滚和俯仰可以采用相同参数；获得合适的基础参数后，再分别观察两者的响应特性进行微调。对于结构和动力系统高度对称的无人机，可不进行单独调整。偏航（Yaw）的调校过程与横滚、俯仰类似，但通常可将D增益设置为0。

**比例增益（P）：**P值应尽可能提高，但需避免产生明显振荡。P过高：无人机出现高频振荡，姿态响应不稳定；P过低：无人机响应迟缓，跟随遥控输入的能力较弱。

**微分增益（D）：**D值应设置在能够有效抑制过冲的范围内，同时避免过度放大传感器噪声。D过高：角速度控制容易受到噪声影响，可能导致电机输出快速波动；D过低：无人机在阶跃输入或快速姿态变化后容易出现过冲和振荡。

**积分增益（I）：**I过高：容易产生低频、缓慢的振荡；I过低：稳态误差较大，受到外界扰动后姿态恢复能力较弱。

<div style="background-color: #f1f1d1ff; border-left: 7px solid #b9b625ff; padding: 10px 15px; margin: 15px 0; border-radius: 3px;">
<strong>​​​💡 调参测试模式：<br>
调参过程中，可在自稳模式或手动姿态控制模式下进行测试，通过观察无人机对遥控输入的响应速度、振荡幅度、过冲以及姿态恢复能力，逐步确定合适的P、I、D参数。每次只调整一个参数，调整幅度不宜过大，调整后进行飞行测试并记录日志，通过日志分析评估调参效果。

</strong>
</div>

## 2\.常见问题排查

**QGC无法连接飞控：** <br>
1\)检查USB数据线是否支持数据传输（部分充电线只能充电）；2\)检查飞控驱动是否正确安装；3\)确认飞控是否正常上电，指示灯是否正常；4\)尝试更换USB接口或数据线。

**日志列表为空：**<br>
1\)确认飞控中已有飞行记录，至少完成过一次飞行；2\)检查SD卡是否正常工作，是否有足够存储空间；3\)尝试点击"刷新"按钮重新读取日志列表；4\)如果SD卡损坏，需要更换SD卡。

**Flight Review上传失败：**<br>
1\)检查日志文件是否完整，文件大小是否正常；2\)确认网络连接是否正常，能够访问review\.px4\.io；3\)尝试使用其他浏览器或清除浏览器缓存；4\)如果日志文件过大，可以尝试截取部分数据进行分析。

**振动过高无法降低：**<br>
1\)检查飞控是否使用减震垫安装，安装是否牢固；2\)检查电机螺丝是否全部紧固，电机轴承是否有异响或磨损；3\)检查桨叶是否有损伤，是否做过动平衡测试；4\)检查机架螺丝是否紧固，是否存在结构共振；5\)如果以上都正常，可以尝试降低IMU\_GYRO\_CUTOFF和IMU\_DGYRO\_CUTOFF参数。

**PID调参后出现振荡：**<br>
1\)首先降低P增益，观察振荡是否消失；2\)如果振荡仍然存在，适当提高D增益，增强阻尼效果；3\)检查滤波器截止频率是否设置过高，导致噪声进入控制环；4\)确认振动水平是否在可接受范围内，振动过大也会导致振荡；5\)如果是低频缓慢振荡，可能是I增益过大，需要降低I增益。
